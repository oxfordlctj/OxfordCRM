# Совет директоров: личная платформа советников

Веб-приложение с личным советом директоров: 15 ИИ-советников по бизнесу (под сеть языковых центров Oxford, Душанбе) и по всем сферам жизни. Работает на Claude.

## Что умеет

| Раздел | Что делает |
|---|---|
| **Главная** | Быстрый вопрос совету, открытые поручения, решения на пересмотр, последние заседания и разговоры |
| **Совет** | Заседание: каждый выбранный советник излагает позицию, затем они спорят (раунд дебатов), а Председатель подводит итог с планом действий. Режимы «полное» и «экспресс» |
| **Советники** | Личный чат один на один с любым советником, история разговоров, кнопка «🧠 Запомнить», которая сохраняет важные факты в память совета |
| **Решения** | Итог заседания одним кликом превращается в решение и поручения с кураторами и сроками. Контроль исполнения, пересмотр, архив |
| **Досье** | Всё, что советники знают о вас: бизнес, филиалы, цели, финансы, здоровье, семья, а также память из разговоров |

**Состав совета.** Бизнес: Председатель, Стратег (CEO), CFO, CMO, Продажи, COO, HR, Академический директор, Юрист. Жизнь: Личный финансист, Врач-консультант, Тренер и нутрициолог, Психолог и коуч, Советник по семье, Наставник. Каждого можно отредактировать или отключить, можно добавить своих.

## Технологии

Next.js 15 (App Router, TypeScript), Tailwind CSS 4, PostgreSQL + Drizzle ORM, Claude API (`@anthropic-ai/sdk`, модель `claude-opus-5-5`, потоковые ответы). Вход по одному паролю.

## Запуск на своём компьютере

Нужны Node.js 20+ и PostgreSQL.

```bash
npm install
cp .env.example .env      # заполните переменные (см. ниже)
npm run setup             # создать таблицы и наполнить советников
npm run dev               # http://localhost:3000
```

Без ключа Claude можно поставить `CLAUDE_MOCK=1`: советники будут отвечать заглушками, и так удобно проверять интерфейс.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `ANTHROPIC_API_KEY` | Ключ Claude API: console.anthropic.com → API Keys |
| `ANTHROPIC_MODEL` | Модель, по умолчанию `claude-opus-5-5` |
| `APP_PASSWORD` | Пароль для входа |
| `AUTH_SECRET` | Длинная случайная строка для подписи сессии (`openssl rand -hex 32`) |
| `CLAUDE_MOCK` | `1` включает тестовый режим без обращения к Claude |

## Публикация в интернет (Vercel + Supabase)

1. **База.** Создайте бесплатный проект на supabase.com, затем Project Settings → Database → Connection string → **Transaction pooler** (порт 6543). Скопируйте строку.
2. **Ключ Claude.** На console.anthropic.com пополните баланс и создайте API-ключ.
3. **Хостинг.** На vercel.com нажмите Add New → Project и импортируйте этот репозиторий.
4. В настройках проекта на Vercel (Environment Variables) добавьте `DATABASE_URL`, `ANTHROPIC_API_KEY`, `APP_PASSWORD`, `AUTH_SECRET`.
5. Нажмите Deploy. При сборке скрипт `vercel-build` сам создаст таблицы и советников. Повторные деплои ваши данные и правки не перезаписывают.

Полное заседание с 8 советниками обычно длится 1–3 минуты. Лимит одного запроса на Vercel выставлен в 300 секунд.

## Стоимость Claude

Оплата идёт по объёму текста. Ориентиры для `claude-opus-5-5`: обычное сообщение в чате стоит примерно 2–5 центов, полное заседание с 8 советниками примерно 30–60 центов, экспресс-заседание примерно вдвое дешевле. Посмотреть расход можно на console.anthropic.com → Usage.

## Важно

Советы ИИ не заменяют живого врача, юриста или налогового консультанта. Советники сами напоминают об этом в чувствительных вопросах.

## Структура

```
src/
  app/(app)/        страницы: главная, совет, советники, чаты, решения, досье
  app/api/          чат, прогон заседания, проект решения, извлечение памяти, вход
  components/       интерфейс (чат, заседание, формы)
  db/               схема БД, миграции, характеры советников (advisors-seed.ts)
  lib/              Claude, контекст досье, авторизация, серверные действия
drizzle/            SQL-миграции
```
